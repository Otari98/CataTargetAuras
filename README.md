# CataTargetAuras

> [!WARNING]
> Requires [ClassicAPI](https://github.com/brues-code/ClassicAPI/releases)

This addon backports TargetFrame debuffs/buffs from Cataclysm (4.3.4 client) to Vanilla (1.12.1 client). You can see all 32 buffs and 16 debuffs, auras casted by you are larger than the rest, auras that you can dispel/purge are highlighted, cooldown sweep animations.

Designed to be used with default UI.
